# OnePlus 15: переключение частоты — DECEPTNKOH Preview (`v1.9.0-preview.4`)

Экспериментальный форк модуля KernelSU / Magisk для **OnePlus 15 (`CPH2747`, ColorOS 17)**, открывающий режим **165 Гц** с сохранением **LTPO-сброса частоты в простое**, безопасным патчингом XML, корректным жизненным циклом демона и восстановлением исходной настройки частоты пользователя.

> **Статус:** Экспериментальный пререлиз (`v1.9.0-preview.4`, коммит `3b019e7` в ветке `main`). Автообновление через `updateJson` в preview-сборках отключено.

## Что реализовано и исправлено

- **Защищённый патчинг XML (`xmlguard` и `sed/`):** Перед bind-монтированием поверх `/my_product/etc/refresh_rate_config.xml` в `post-fs-data.sh` пропатченный XML проверяется валидатором `module/bin/xmlguard.jar` (исходник `tools/XmlGuard.java`). Параметр `FORCE_ALL` позволяет либо разрешить `165 Гц` во всех приложениях (`1`), либо учитывать штатные ограничения (`0`).
- **Совместимость с KernelSU (`ksud`):** Из `SHA256SUMS` исключены записи `META-INF/*`, так как `ksud` не распаковывает `META-INF` в каталог модуля при установке.
- **Жизненный цикл демона и LTPO (`vrrd.sh`, `lifecycle.sh`, `service.sh`):** Переключает `oplus_customize_screen_refresh_rate` между активным режимом (`ACTIVE_MODE=7` / `165 Гц`) и простоем (`IDLE_MODE=1` / LTPO-слот) с учётом `IDLE_TIMEOUT` (по умолчанию `2` с), `DEBOUNCE` (`0.5` с), списка удержания частоты `KEEP_ACTIVE_PKGS`, правила `WIN_OVERRIDE` (`camera` / `all` / `off`) и логики работы с камерой (`CAMERA_165`, `CAMERA_PKGS`, `KEEP_ACTIVE_CAMERA`, `LEARN_CAMERA_USERS`).
- **Точка возврата пользовательской настройки (`settings-state.sh`):** Сохраняет исходное значение настройки пользователя до первой записи демона и возвращает его при штатной остановке или удалении модуля, не затирая существующий снимок при перезапуске.
- **Автотесты и сборка (`tests/`, `tools/`, `.github/workflows/build.yml`):** Включает набор проверок `sh tests/all.sh` и сборку архива через `python3 tools/package.py --source-revision <sha>`.

## Установка и проверка

1. Скачай `OnePlus15-165HZ-LTPO-v1.9.0-preview.4.zip` со страницы [GitHub Releases](https://github.com/DECEPTNKOH/OnePlus15-165HZ-LTPO/releases/tag/v1.9.0-preview.4).
2. Установи архив через **KernelSU / SukiSU** (или командой `ksud module install <путь_к_zip>`) и **перезагрузи** устройство. KernelSU удаляет `customize.sh` после установки — его отсутствие после прошивки ожидаемо, остальные файлы должны совпадать с `SHA256SUMS`.
3. Проверь монтирование, процесс демона и текущую частоту:

```sh
mount | grep refresh_rate_config.xml
ps -ef | grep vrrd.sh
dumpsys display | grep -E "mBaseDisplayInfo|renderFrameRate|165"
```

> **Важно при обновлении и эксплуатации:** При установке preview-архива `vrr.conf` перезаписывается значениями по умолчанию — заранее сохрани свои `KEEP_ACTIVE_PKGS`, `IDLE_TIMEOUT` и `DAEMON`. Не копируй вслепую старую резервную копию `v1.8` с небезопасной логикой работы по PID. Для возврата к штатной системе сначала отключи модуль и перезагрузи устройство.

## Что подтверждено, а что не подтверждено

- **Подтверждено на устройстве:** Проверенный XML реально смонтирован поверх штатного файла; процесс принадлежит `vrrd.sh`; при активном взаимодействии выбирается `165 Гц`, в простое частота снижается; корректно работают сохранение и восстановление настройки (`1` -> `7`) и повторный запуск демона; проходят тесты и сборка `package.py`.
- **Не подтверждено аппаратно:** Физические `1 Гц` панели отдельно не измерялись; `min_fps` и `test_te` могут показывать программное состояние, отфильтрованные значения или резервные метрики. Длительная автономность и все сценарии игр/камеры/видео остаются на уровне экспериментального превью.
